About

Building AI that
actually ships.

( Who )

I'm Sayan Dutta, an AI engineer and B.Tech student in Robotics & Artificial Intelligence at UEM Kolkata. I build things end-to-end — from the prompt and the retrieval layer all the way down to the Terraform that provisions them.

My work lives at the intersection of large language models, vector and graph databases, and cloud infrastructure. I've shipped RAG pipelines, multi-agent systems, agentic developer tooling, and a bias-mitigation platform — each one live, not a notebook demo.

I care about systems that are fast, explainable, and production-ready. Most AI projects die in the gap between "works on my machine" and "survives real traffic." I spend most of my time in that gap — streaming, error handling, account rotation, canary deploys.

When I'm not shipping, I'm sharpening fundamentals — data structures, algorithms, and systems design — because the infrastructure under the model matters as much as the model.

How I work

What I do

  • Ship to a live URL, then iterate — deployment is step one, not the finale.
  • Reach for managed cloud primitives so the system runs without babysitting.
  • Instrument and stream, so failures are visible instead of silent.
  • Write infrastructure as code — reproducible beats clever.

What I don't

  • Ship thin API wrappers dressed up as products.
  • Leave a model running without guardrails or a kill switch.
  • Confuse a working demo with a working system.
  • Optimize for the screenshot instead of the load.
